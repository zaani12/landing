Common Questions

FAQ

Quick answers for merchants evaluating OpsPilot for daily store operations and workflow automation.

What does OpsPilot automate? +

OpsPilot automates operational follow-up across orders, customers, products, inventory, abandoned checkouts, and scheduled review workflows.

Do I need technical knowledge to build workflows? +

No. You can start from templates or use the visual builder to configure triggers, conditions, and actions without writing code.

Can OpsPilot alert my team outside Shopify? +

Yes. OpsPilot supports Slack alerts, workflow emails, and Google Sheets logging so teams can stay aligned across tools.

Is OpsPilot useful for teams, not just solo merchants? +

Yes. It includes task assignment, notes, activity history, and shared workflow-driven follow-up so multiple operators can work from one system.

Can I test workflows before relying on them? +

Yes. The app includes test actions such as running scheduled workflows manually or testing with the latest order, product, customer, checkout, or inventory payload.

Can I start with templates and customize later? +

Yes. You can use built-in templates as a starting point, then adjust the trigger, conditions, actions, integrations, and activation status at any time.
